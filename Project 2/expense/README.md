# Expense Tracker

A simple and clean **Expense Tracker** web interface built using **HTML and CSS**.

## 📌 Project Overview

This project is a beginner-friendly expense tracker interface where users can enter an expense name and amount. The page displays the expense section and total amount area in a simple, organized layout.
I used basic programming concepts and functions such as append() to add expenses, pop() to remove expenses, and addition operations to calculate the total amount spent. The project also uses Flask to connect the Python backend with the HTML and CSS frontend.

## ✨ Features

* Add New Expense section
* Expense name input
* Amount input
* Add Expense button
* Your Expenses section
* Total Spent display
* Clean and responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3
* Python Programming
* Flask

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `app.py` in your browser.
4. The Expense Tracker interface will appear.
