# 📝 To-Do List (Python)

A simple command-line **To-Do List** application developed in **Python**. 
This project allows users to manage their daily tasks through a menu-driven interface, making it easy to add, view, update, and delete tasks.

## 🚀 Features

* ➕ Add new tasks
* 📋 View all tasks
* 🗑️ Delete tasks
* 💻 Easy to use and beginner-friendly

## 🛠️ Technologies Used

* Python Programming

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program:
       python todo.py

## 🎯 Project Objective

This project was created to practice Python fundamentals, append, loops, list, functions.
