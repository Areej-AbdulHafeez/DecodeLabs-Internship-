# Password Generator 🔐

A simple **Python Password Generator** that creates strong and random passwords using letters, digits, and special characters.

## Features

* Generate secure passwords
* Uses uppercase and lowercase letters
* Includes numbers and special characters
* Allows the user to choose the password length
* Simple and beginner-friendly Python project

## Technologies Used

* Python
* `random`
* `string`

## How to Run

1. Clone or download the repository.
2. Open the project in VS Code or any Python editor.
3. Run the Python file:
         python password_generator.py
4. Enter the desired password length.
5. Your generated password will be displayed.


## Purpose

This project was created to practice **Python basics, variables, loops, conditions, user input, and modules**.
